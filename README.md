# AI Sandbox – Blockchain API Lab

This project contains small Python scripts exploring:

- Ethereum price via Etherscan API (v2)
- Ethereum wallet balance queries
- Secure environment variable usage
- JSON parsing and API debugging

## Setup

Activate virtual environment:

venv\Scripts\Activate

Set API key (PowerShell):
$env:ETHERSCAN_API_KEY="YOUR_KEY"

## Run Scripts

Price:
python .\scripts\01_eth_price_v2.py

Wallet balance:
python .\scripts\02_wallet_balance_v2.py
